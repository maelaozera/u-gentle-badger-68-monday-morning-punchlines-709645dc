## The joke

> My bed filed a restraining order against my Monday alarm, and honestly, I'm testifying for the bed.

One line, 99 characters. Instead of another "I hate Mondays" complaint, the joke
turns the Monday alarm into a courtroom drama: the bed files a restraining
order against the alarm, and the punchline sides with the bed — the one thing
every Monday morning actually wants to stay in.

## How it works

`main.ts` is a dependency-free Node 22 TypeScript program. It holds the joke
as a single string, self-checks it (1–200 characters, not only whitespace,
single line), then writes it exactly to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Then read the entry back:

```sh
cat /output/entry.txt
```
